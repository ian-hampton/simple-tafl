## Simple Tafl

Play a game of Simple Tafl (11x11).

### Rules
* All pieces can move horizontally and vertically.
* A piece is captured if it is sandwiched vertically or horizontally by two rival pieces. However, a piece is only captured if the trap is closed by the other player. Moving in between two rival pieces does not cause a capture.
* The Defender (white) wins if the King reaches any edge space.
* The Attacker (black) wins by capturing the King or by encircling all Defender pieces.

### Prerequisites
* Built with Python 3.14.X and Docker Desktop.

### Installation

1. Clone the repository.
    ```sh
   git clone https://github.com/ian-hampton/simple-tafl
   ```

2. Launch Docker Desktop.

3. Open your terminal and run `docker compose up`.
